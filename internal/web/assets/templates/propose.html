Proposed skills

Cached propose artefacts. Each card is a model- written suggestion of new SKILL.md files based on recurring patterns in your sessions, persisted in llm_outputs and produced by aichronicles propose. Each skill carries a copy- to-clipboard apply command — paste it in a terminal to materialise the skill on disk.

The web UI never writes to ~/.claude/skills/ on its own — this page only reads cached proposals; you stay in the loop on what gets installed.
