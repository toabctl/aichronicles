Propose

Two views in one page: above is the lifecycle of every skill the system has proposed (what stuck, what didn't); below is the list of recent runs with the model's current suggestions ready to materialise.

The web UI never writes to ~/.claude/skills/ on its own — this page only reads cached proposals; the action surface (aichronicles propose add / merge / discard) stays CLI-only so you're always in the loop on what gets installed.
